## "The story goes" / disputed, framed as such
- How the pyro accident happened (three versions given, no single cause asserted; That Guy verdict explicitly declines to blame one person).
- Axl's exact parting words (quoted differently; script paraphrases).
- Set length and crowd size (ranges given).
- Riverport order of events (accounts differ; kept vague).

## Checked and left out
- "Burned to the bone": Hetfield himself has used "down to the bone" in a later recollection (via UCR), but other sources say second/third degree only. Left out per brief.
- Whether Metallica actually played a Montreal makeup show: not verified, so the script only says Lars promised one.
- "Riot fires": script says rioters "set fires"; widely described in retrospectives but not in the UPI summary I saw. Low risk; cut if you want to be strict.
- Strippers/party stories from the tour, Hetfield's "guitar strings melting," guitar shielding him: unverified, left out.
- Axl stepfather/"Bill Bailey"/arrest-count stories: only on low-quality sites, left out.
